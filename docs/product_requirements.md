# 产品需求文档 (PRD)

## 1. 产品定位

面向蓝牙开发/测试工程师的在线 btsnoop 实时解析工具，替代 "导出文件 → 本地 Wireshark 分析" 的传统流程。

**一句话描述：** 打开浏览器，拖入文件或连接设备，即刻看到蓝牙协议解码结果。

## 2. 目标用户

| 角色              | 核心诉求                              | 使用频率    |
|-------------------|---------------------------------------|-------------|
| 蓝牙固件工程师    | 快速定位 HCI 层交互异常               | 每日        |
| 蓝牙应用开发      | 验证 GATT 读写、A2DP 协商是否正确     | 每日        |
| 测试工程师        | 批量分析测试抓包，筛选失败用例        | 每周        |
| 技术支持          | 远程收到用户抓包，在线查看不装工具    | 按需        |

## 4. MVP 定义

**MVP = US01 + US02 + US03 + US04 + US05**

即：文件上传解析 + 包列表 + 协议树 + HexView + 基础过滤 + AVDTP/A2DP Codec 解析

MVP 不包含：实时流、导出、协作、状态机可视化

**MVP 交付标准：**
- 能正确解析 bt-snoop-live 支持的所有协议和 Codec
- 解码结果与 Wireshark 对比无差异（覆盖 90% 字段）
- 10 万条包页面不卡顿
- 可通过 Docker 一键部署

## 5. 功能优先级矩阵

```
         高价值

    P1     │    P0 (MVP)
  实时流   │    文件解析
  统计面板 │    协议解码
  导出     │    过滤

    ───────┼──────────────
    P3     │    P2
  AI分析   │    协作共享
  Profile  │    对比分析
  语义     │    pcapng导出
           │
         低价值
    低频率          高频率
```

## 6. 非功能需求

| 维度     | 要求                                      |
|----------|-------------------------------------------|
| 性能     | 100MB 文件解析 <3s，首屏 <500ms           |
| 容量     | 单文件最大 2GB，单会话最大 500 万条包     |
| 可用性   | 会话 30 分钟过期，不存储用户数据          |
| 兼容性   | Chrome/Firefox/Edge 90+，btsnoop v1 格式  |
| 安全     | 无持久存储、无用户注册、支持私有部署      |
| 部署     | Docker 一键部署，内存 <4GB                |

## 7. 不做的事情 (Out of Scope)

- 不做 pcap/pcapng 格式的原生支持（MVP 阶段）
- 不做用户系统和权限管理
- 不做数据持久化存储
- 不做移动端适配
- 不做 Wireshark 的全协议栈覆盖（聚焦蓝牙常用协议）
- 不做 BR/EDR baseband 层解码

## 8. 与 bt-snoop-live 的关系

bt-snoop-live（已有 Python 脚本）是终端版原型，Web 版需要：

| 能力                    | bt-snoop-live | Web 版  | 说明                        |
|-------------------------|---------------|---------|----------------------------|
| btsnoop 解析            | ✅            | ✅      | 逻辑一致                   |
| HCI 解码                | ✅            | ✅      | 查表一致                   |
| L2CAP + CID 映射        | ✅            | ✅      | 状态机需更完整             |
| AVDTP 信令              | ✅            | ✅      | 逻辑一致                   |
| A2DP Codec (含LHDC)     | ✅            | ✅      | 参数解析逻辑直接复用       |
| ATT/GATT 深度解码       | ❌ (仅协议名) | ✅      | 需要新增                   |
| SMP 深度解码            | ❌ (仅协议名) | ✅      | 需要新增                   |
| 过滤表达式              | 简单层过滤    | ✅      | 升级为结构化表达式         |
| 实时 ADB               | ✅            | ✅      | 架构改为 Proxy + WebSocket |
| 协议树/HexView         | ❌            | ✅      | Web 独有                   |
| 虚拟滚动               | 不需要        | ✅      | Web 必须                   |
